ยังไม่เปิดใช้งาน กำลังพัฒนา

หน้านี้จะรวมสิ่งที่เปลี่ยนไปนับจากข้อมูลรอบก่อน — ไม่ใช่ข่าวจากสำนักข่าว เพราะ ก.ล.ต. ไม่มี API ข่าว แต่เป็นการเทียบข้อมูลสองรอบ:

  • กองที่เพิ่งส่ง Fact Sheet ใหม่
  • ประกาศจ่ายปันผล (ต้องต่อ endpoint dividend-history)
  • กองเปิดใหม่ที่กำลังเสนอขาย (endpoint ipos)
  • ค่าธรรมเนียมหรือระดับความเสี่ยงที่เปลี่ยน
  • สัดส่วนทรัพย์สินที่ขยับจากรอบก่อน

ต้องเก็บข้อมูลรอบก่อนไว้เปรียบเทียบก่อน จึงจะเริ่มมีอะไรให้แสดง
